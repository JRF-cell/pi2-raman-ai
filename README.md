# PI² Project 156 - AI-Assisted Raman Analysis

ESILV A4 PI² Project 156.

## Project Title

**AI-Assisted Raman Analysis for 2D Electronic Device Quality Control**

## Objective

The objective of this project is to develop an AI-assisted tool for the automated analysis of Raman spectra from 2D materials.

The project will focus on:

- Raman spectral preprocessing
- Peak detection and feature extraction
- Classification of 2D materials
- Comparison of Machine Learning and Deep Learning models
- Robustness evaluation
- Spectral quality and defect analysis
- Development of a web application
